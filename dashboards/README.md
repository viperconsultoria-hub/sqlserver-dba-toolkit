# Dashboard datasets

These queries provide transparent starting datasets for Power BI and Grafana. They are not a turnkey monitoring service.

For reliable history, collect compact snapshots into a dedicated monitoring repository, preserve UTC timestamps and source-instance identity, calculate deltas for cumulative counters, and expose read-only reporting views.
